## 由来

**designer が `/design` で作成した**（2026-08-23）。`meta/adr/0050` が定めた経路——orchestrator が
自分で画面を描かず、designer を起動して `/design` で行う——を通った**最初の成果物**である。

土台は `design/explorations/` の3枚だが、**中身は契約から引き直している**。作法（手描き調・
破線＝未確定・ねらいとトレードオフの併記）だけを引き継いだ。`design/explorations/` は orchestrator が
直接描いたもので designer のパイプラインを通っておらず、その由来の問題を本ディレクトリは持たない。

人間の評価（2026-08-23）:

> とてもセンスのいいワイヤーフレームですね（略）凡例もよい、ワイヤフレームの書き方も次からこの形式が良いです

この評価を受けて作法を `meta/templates/wireframe.md` に雛形として起こした。

## 位置づけ（重要）

- **承認済みの設計骨格ではない。** 承認点①（契約と設計骨格）にはまだ出していない
- **図に描かれているものの一部は、現行契約が明示的に禁じている**。基点マーカー・徒歩圏の同心リング・
  カードの徒歩時間・徒歩の上限は `ADR-0025` が承認したが、マージ済み契約は
  `candidate-search-browser-interface.yaml` の `forbiddenTestIds`（310行）と
  `bodyMustNotExposeTestIds`（795行）に `candidate-origin-marker` を置いたままで、
  `candidate-search.feature:84` は「徒歩時間は示されない」と明記している。
  **`Legend.dc.html` はこれらをすべて破線にし、根拠の行番号とともに一覧にしてある**
- 実装・契約・`design/reconciliation/` と食い違う場合は、**常にそちらが正**

## 決着している判断（人間裁定 2026-08-23）

1. ジャンル行の「ほか N件…」は**行の左端に固定**する（折り返しは採らない。2026-08-14 の見送りを維持）
2. 候補の取得に失敗したとき、直前まで表示していた候補を**残す**
3. 件数の予告は**適用ボタンにだけ出す**（常時表示は置かない）
4. **PC版は今回の合意対象に含めない**

いずれも「人間は決めたが契約はまだ追いついていない」状態にある。3件とも現行契約に**違反はしない**が、
契約が位置や存否を定めていないため、**実装が元へ戻しても受け入れテストは通る**。保証するなら契約への
追補が要る（`Legend.dc.html` の「契約の確認結果」節に architect への申し送りとしてまとめてある）。

## まだ決めていないこと

エラー時の画面状態（`product-brief.md` §8 で未決）——429（レート制限）と 503（取得不能）を画面で
区別するか／0件のとき契約どおり地図ごと消えるのを受け入れるか／「絞り込みを見直す」を押せるものに
するか。`EmptyError.dc.html` に破線のまま残してある。

## ADR-0002 への対応

店名・ジャンル・徒歩の分数・件数・地図はすべて**合成値**である。実在の店舗データ・provider由来の値・
実在の地名・座標・既定探索距離を含まない（配置前に機械検査済み）。

## `ADR-0003` 決定2 との関係（**解消済み**）

`adr/0003` 決定2 は `design-preview`（レビュー専用receiver）に「検索基点」「数値距離」を置くことを
禁じており、`ADR-0025` で両方が製品の表示物になったことと衝突していた。**2026-08-24、人間の判断で
`design-preview` を廃止した**（`adr/0028`）ため、この条文が掛かる対象そのものが無くなり、矛盾は消えた。
本ディレクトリは元々 `design-preview` ではなく、直接には当たっていなかった。

## 寸法について

**図に現れる寸法・「何件見えるか」はすべて作図上の値であり未実測である**（`meta/adr/0059` 決定5）。
designer は自分の図を描画して測る手段を持たない。判断がこれらの数字に依存する場合は orchestrator が
実測する。特に次の2つは未実測である——M1 で5件のうち画面に入る件数、ジャンル行の左端固定で右の
スクロール域に入るチップ数。
