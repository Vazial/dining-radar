## どう確かめたか

- 板: `dining-radar-party2-c2r2.html` を Chromium ヘッドレスで開き、F2 PC のアートボードを 1336×920 で撮影した。

  - 撮影した幅は 390、1024、1280、1440、1920。768 は 3日分のときだけ。

- 実行できなかったもの: `client-js-tests` の vitest は `node_modules` が無く `ERR_MODULE_NOT_FOUND` で動かせなかった。JS 単体テストの回帰は判断できない。

## 画像で確認できた内容（板との一致）

1440×900 と 1280×800 の実装画像を、板の画像と並べて見た。

1. **左に1枚のカード**: 上に「答えた 3 / 3」と区切り棒、その下に 日｜○△×｜あなた の表がある。枠の角丸と罫線も板どおり。表の見出し帯は薄い緑で、○△×の記号は色つき。
2. **日の表**:
   - 日付は太字で、○の数だけ濃く、△×は灰色。
   - 「あなた」は丸印で、○は緑、△は橙、×は灰の塗り。
   - 未回答は点線の輪になる（12日分の画像で確認）。
   - 有力の日には緑の「有力」の札が付く。
3. **左線**: 選んだ行は薄緑の塗りと黒の太い左線。選んでいない有力の日は緑の左線になる（12日分で10/16が該当）。板の2段（黒＝選択、緑＝有力）と同じ。
4. **右の列**: 日詳細カードの中に、みんなの答えの棒、名前、「あなたは行けますか」の3ボタンがある。「前の日」「とばす」はカードの下。
5. **名前は2列**: 1024、1280、1440、1920 のすべてで2列。幅が広くても1列にならない。
6. **「…にしました」の位置**: 右カードの上の行にある。棒の下ではない。
7. **区切り棒**: 左カードの中にあり、右カードの上の全幅ではない。
8. **スマホ（390×844 の3日分・12日分、360×740、768×1024）**: 区切り棒＋「日の一覧」ボタン、「…にしました」、全幅カード、名前1列。広い画面側の変更の影響は見えない。差分上も、狭い側の分岐（`isWideDayListLayout` が偽）は従来の描画のまま。
9. **幅の崩れ**: 1024、1100、1280、1440、1920 で横スクロールは出ていない。1920 では外枠が 80rem で止まり、左右に余白ができる。板は 1336 幅なので許容範囲。

## 契約・構造の不変性

- `data-testid`（`gathering-participant-day-list`、`day-item`、`day-list-open`、`gathering-schedule-response-option` など）と `data-*` 属性は、差分上すべて同じ要素・同じ名前のまま。変わったのは配置とクラスだけ。
- `renderDayListRow` の行ボタン本体と `data-*` は幅の広い形と狭い形で共有されている。広い形だけ中のセル構造が変わった。
- 広い形では進行行（`renderProgressRow`）を左カードに移し、狭い形では従来の場所に残している。進行行の testid は常に1組だけ（二重にならない）。
- 日付の文字は広い形では「10/13 (火)」だけで、時刻（12:00 から）は左の表に出さない。板どおり。

### Minor

1. **M-1 広い形の行から数のラベルが消えた**。従来は文字で「○2 △1 ×1」と読めた。今回は数字3つだけで、各数字が何の数か（行ける・たぶん・むり）がボタン内の文字から分からなくなった。「あなた」の丸印は `role="img"` と `aria-label` を付けているので分かる。スクリーンリーダーでは列見出しの記号頼みになる。板の見た目は満たしているので、必要なら数の各セルに `aria-label` を足すのが望ましい（対応は任意）。
2. **M-2 灰色の文字のコントラスト**。表見出しと△×の数は `#77827a`（10.5〜13px）で、白や `#eaf0ea` の上では約 3.4〜4.1 になり、4.5 を下回る。板と同じ色で、既存の xfail（淡いグレー文字）と同じ系統。新たに増えた箇所なので、`test_layout_sanity` の xfail の説明に含める判断が要る。
3. **M-3 左カードが `position: static` になった**。以前の幅の広い形の `.gth-day-panel` は追従する（sticky）指定だったと読める。12日分では表が 800px を超えてページが伸びるが、右カードのボタンは最初から視野内（y≈640）にあり、実害は見えなかった。14日・30日など多い場合の挙動は撮影していない。
4. **M-4 名前が長いと狭い幅で3行に折り返す**。24文字の名前は 1024 幅で3行になり、そのセルだけ高さが伸びる（はみ出しや重なりはない）。1280 以上では2行、1440 では1行。板に長い名前の絵は無い。

### Info

- **I-1** 見出しの2行目「回答者: ケン」と上部バーの2段構成は板（1本のバー）と違うが、A-1（KEN-53）の範囲で、今回の差分の対象外。
- **I-2** 有力の日が複数ある場合、札も複数出る（12日分で10/13と10/16）。これは既存の同点処理で、今回の変更ではない。
- **I-3** 選んだ行が有力の日のときは、左線は黒（選択）が優先される。板の2段の意図と合っている。
